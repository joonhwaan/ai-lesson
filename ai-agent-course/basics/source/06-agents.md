지금까지 우리는 AI 모델이 도구를 호출해 기능을 확장할 수 있다는 것을 배웠습니다. 그렇다면 여러 도구를 호출하고, 어떤 도구를 쓸지 스스로 결정하며, 결과에서 학습하도록 하면 어떨까요? 바로 그때 에이전트가 등장합니다.

본질적으로 에이전트는 반복 루프 안의 도구 활용입니다.

이렇게 생각해 보세요. AI에게 단계별로 지시하는 대신 목표만 제시하고, 필요한 단계는 스스로 찾게 하는 것입니다. 누군가에게 길을 턴마다 안내하는 것과 목적지만 알려주고 GPS로 찾아가게 하는 것의 차이와 같습니다.

에이전트가 실제로 작동하는 방식
예를 들어 AI 에이전트에게 "설정 페이지에 다크 모드 토글을 추가해줘"라고 요청한다고 해봅시다. 에이전트는 먼저 코드베이스를 검색해 설정 페이지를 찾습니다. 관련 파일을 찾으면 현재 구조와 스타일링 방식을 파악하기 위해 내용을 읽습니다.

그다음 흥미로운 일이 일어납니다. 에이전트가 기능 구현을 위한 자체 계획을 세웁니다. 상태 변수를 추가하고, 새 CSS 클래스를 만들고, 토글 컴포넌트를 구현하고, UI를 업데이트하기로 결정할 수 있습니다. 각 단계를 실행하면서 지속적으로 작업을 점검하고, 테스트를 돌리며, 발생한 오류를 수정합니다.

이 전체 과정은 일련의 도구 호출로 진행되며, 에이전트는 각 작업 결과를 바탕으로 다음 행동을 결정합니다. 마치 누군가가 생각을 소리 내어 말하는 것을 보는 듯하지만, 실제로 작업을 진행하며 결과를 내고 있습니다.

에이전트는 빌드 방식을 바꿉니다
에이전트의 진짜 강점은 개발자인 당신의 역할을 바꾼다는 데 있습니다.

"components 폴더에 어떤 파일이 있지?", "Button 컴포넌트를 읽어줄래?", "이제 다크 모드 버전을 추가해줘"처럼 단계별로 요청하는 대신, 최종 목표만 밝히면 에이전트가 과정을 알아서 처리합니다.

이는 큰 변화입니다. 당신을 작업 수행자에서 작업 관리자로 전환하기 때문입니다. 여러 에이전트를 동시에 돌려 코드베이스의 서로 다른 부분을 처리할 수 있습니다. 한 에이전트가 인증 플로우에 테스트를 추가하는 동안, 다른 에이전트는 문서를 업데이트하고, 세 번째는 미뤄둔 지저분한 유틸리티 파일을 백그라운드에서 리팩터링할 수 있습니다.

에이전트와 함께 일하는 현실
에이전트는 기존 코드에 테스트를 추가하고, 문서를 업데이트하고, 일관된 패턴으로 리팩터링하며, 명확한 오류 메시지가 있는 버그를 수정하는 등 목표가 뚜렷하고 패턴이 정해진 작업에 강합니다.

반면, 시스템 상호작용에 대한 깊은 이해가 필요한 복잡한 디버깅, 픽셀 단위까지 시각적 디자인 목업을 완벽히 맞추는 작업, 학습 데이터에 없던 새로운 라이브러리를 다루는 작업 등에는 여전히 어려움을 겪습니다.

에이전트를 명확한 지시가 필요하고, 기억이 쉽게 누락될 수 있어 감독이 필요한 빠른 주니어 개발자로 생각하세요. 이들은 다른 전략이 필요하다는 걸 인식하지 못한 채 같은 실패한 접근을 반복하며 루프에 빠질 수 있습니다.

에이전트는 다수의 도구 호출과 반복 때문에 단순히 질문하는 것보다 훨씬 더 많은 토큰을 사용합니다. 적절한 제약이 없으면 의도하지 않은 변경을 열정적으로 수행할 수 있습니다. 그리고 무엇보다, 코드가 올바르게 동작하고 기준을 충족하는지 검증하는 책임은 여전히 사용자에게 있습니다.

위임의 기술

목표는 인간의 개입을 없애는 것이 아니라 여러분이 달성할 수 있는 범위를 확대하는 것입니다. 여러분은 설계자이자 검토자가 되고, 에이전트는 구현 세부를 맡습니다.

앞으로의 내용
토큰, 컨텍스트, 도구, 에이전트까지 AI 모델의 기초를 살폈습니다. 다음 강의에서는 Cursor에서 이 개념들을 실제로 적용해 소프트웨어를 만드는 실전 예제를 다룹니다.

더 나은 결과를 이끌어내는 프롬프트 구성 패턴, 컨텍스트 제한에 걸리지 않도록 긴 대화를 관리하는 방법, 에이전트에 작업을 효과적으로 위임하는 법, 올바른 검증 워크플로를 구축하는 법, 그리고 문제가 생겼을 때의 디버깅까지 배우게 됩니다.

AI와 함께 일하는 역량은 연습할수록 향상됩니다. 이번 기초 강의에서 구축한 멘탈 모델은 왜 특정 접근 방식이 다른 것보다 더 잘 작동하는지 이해하는 데 도움을 주어, AI의 도움으로 소프트웨어를 더 효과적으로 만들 수 있게 해줍니다.
