# AI 에이전트 입문 과정

비유와 그림으로 AI의 핵심 멘탈 모델을 익히고, 코딩 에이전트로 실제 개발하는 법까지 다루는 **초보자용 과정**입니다.
본격적인 [10세션 심화 과정](../advanced/site/index.html)으로 이어지는 워밍업으로 설계되었습니다.

- **1부 (레슨 00~06) — 기초 멘탈 모델**: AI가 어떻게·왜 그렇게 동작하는가 (코드 없이 개념 중심)
- **2부 (레슨 07~12) — 코딩 에이전트 실전**: 에이전트로 코드베이스를 이해하고, 기능을 만들고, 디버깅·리뷰하는 전략
- **레슨 13 — 전체 정리**: 엔드 투 엔드 예제 + 12개 멘탈 모델 + 심화 과정 로드맵

> 원천 자료: `source/` 의 13개 문서("AI 기초" 01~06 + "코딩 에이전트 실전" 07~13)를 초보자 친화적으로 정제했습니다.
> (레슨 `00` AI 시대 이해하기는 원천 없이 새로 추가한 도입 레슨입니다.)
> 2부는 도구 비종속 개념을 중심으로 하되, 구체적인 도구 기능은 "도구 예시(Cursor)" 콜아웃으로 인용합니다.

## 📺 사이트로 보기 (추천)
- **열기**: `site/index.html` 더블클릭 (인터넷 연결 필요 — 렌더링 CDN)
- **다시 빌드**(레슨 md 수정 후): `python site/build.py`

## 각 레슨 공통 형식
- 학습 목표 → 비유 중심 본문(ASCII 다이어그램·표) → 💡 한 문장 요약 → ✅ 확인 문제(정답·해설) → 🔗 다음/심화 연결

## 폴더 구조
```
basics/
├─ README.md
├─ lessons/        ← 정제된 입문 강의(원본 md, 00~13)
├─ source/         ← 입문 원천 자료(정제 전, 01~13)
└─ site/           ← 생성된 입문 사이트
   ├─ build.py      ← md → HTML 변환 (재실행 가능)
   ├─ style.css     ← 밝고 친근한 입문 테마 (../../shared-assets/ 에서 복사)
   ├─ app.js
   ├─ index.html    ← 진입점
   └─ lesson-00~13.html
```
> 공통 디자인 시스템은 저장소 루트의 `../shared-assets/`가 단일 소스이며, 빌드 시 각 사이트로 복사됩니다.
