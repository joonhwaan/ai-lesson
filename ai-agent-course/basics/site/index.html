AI 에이전트 입문

비유와 그림으로 익히는 AI의 핵심 멘탈 모델 + 코딩 에이전트 실전 활용

초보자 친화 개념 + 실전 예시 8주 심화 과정 준비
이 과정은 두 부분으로 이어집니다. 1부(레슨 00~06)는 AI가 어떻게·왜 그렇게 동작하는지 멘탈 모델을 익히고, 2부(레슨 07~12)는 코딩 에이전트로 실제 소프트웨어를 개발하는 실전 전략을 다룹니다. 마지막 레슨에서 전체를 정리하고 8주 심화 과정으로 이어집니다.
